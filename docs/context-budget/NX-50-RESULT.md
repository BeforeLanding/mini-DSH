## 解释边界

- 两批串行、时间窗不同，供应商缓存可能跨会话共享；cache-read 完全相同不构成受控比较。
- 金额是按 provider usage 与冻结峰时价重算的估价，不是供应商账单；旧版实际估价略高。
- 6 题 × 2 次只够做开发门槛；没有置信区间、p 值或正式题库结论。
- 观测到的预览截断与压力压缩说明机制确实触发，但不能把聚合差异单独归因于三项组件优化中的哪一项。
- 本批次使用后，U02/B03/F01/F02/R04/T04 不再是未曝光的正式留出题；未来正式批次必须重新冻结题库。
