## 重复摘要

默认输入目标是65,536 token，主动压力线为 `65,536 × 0.8 = 52,428.8`。2M档 Full 的 RC01/0 第4阶段连续应用18次压力摘要；每次重新投影仍为52,990～54,712 token，全部高于压力线。UC01/0 第4阶段的17次应用后重新投影为53,906～55,068 token，同样全部高于压力线。`planCompaction` 只压当前 task 的连续消息，旧阶段在达到65,536的裁剪目标前仍可留在投影里，所以压缩后压力条件可能原样存在；主循环此前在下一轮再次尝试，形成循环。2M档 Full 合计61次摘要请求、293次总模型请求，对照 Baseline 的179次总请求；这体现了明显开销，不能据此倒推出修复后的成功率。

本次修复在一次已应用的压力摘要后检查重新投影：若仍高于压力线，仅在该 run 里抑制后续主动压力尝试。达到输入目标/窗口边界后的兜底压缩不受抑制；若摘要有效地降到压力线以下，未来新历史再次越线仍可主动压缩。离线模拟分别覆盖“无法降线时只摘要一次”和“有效降线后允许再次摘要”。
