## 判读

按 [NX-51-PRUNE-AB](NX-51-PRUNE-AB.md) 的预注册规则：

- **摘要下降：未成立。** 两臂都执行 12/12，但 `prune-on` 的摘要次数（7 对 3）与摘要耗时（105.4 s 对 43.2 s）都更高，不是 `summary-reduced`。
- **安全：边界通过但出现一条新失败。** 可靠完成 10 对 11（低于 off 1 条，正好触及容差下限）；产物验收 12/12 对 12/12。新增的不可靠完成是 R04/1（`token_budget`），它同时也是主动耗时与输出 token 的最大增量。
- **效率：方向相反。** 主动耗时 +37.7%、输出 token +48.4%，与“更少摘要带来更短墙钟”的假设相反；逐题差值在重复间方向不一致（如 B03/0 与 B03/1、F02/0 与 F02/1），本批不足以把差异归因于裁剪机制。

**结论：这条离线反事实没有在真实轨迹上复现。** 摘要后的旧任务确实被裁掉（事件与投影可核对），但模型在裁剪后的轨迹上生成了更多输出、触发更多摘要；2 次重复与串行时间窗不足以区分采样方差与机制效应。按预注册规则，**不应把“摘要后裁剪”作为默认行为推广**，也不能把本批读成“修复让耗时下降”。
